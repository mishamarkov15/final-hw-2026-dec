# Google Таблицы

Таблица отправляет транзакции и бюджеты в API CashCraft и загружает отчёт о расходах. Нужен запущенный Gateway с публичным HTTPS-адресом: Google Apps Script не может обращаться к `localhost`.

1. Создайте Google Таблицу → **Расширения → Apps Script**. Вставьте содержимое [Code.gs](Code.gs).
2. В настройках редактора включите отображение манифеста `appsscript.json` и замените его содержимым [appsscript.json](appsscript.json).
3. Запустите `setupSheets`, разрешите доступ, обновите страницу таблицы. Появятся листы **Транзакции**, **Бюджеты**, **Отчёт** и меню **CashCraft**. Существующие строки при повторной настройке сохраняются.
4. В меню выберите **Адрес API**, укажите HTTPS-адрес без `/api`, затем **Регистрация / вход**. При регистрации нужен пароль от 8 до 72 байт. Пароль не сохраняется; JWT хранится в пользовательских свойствах скрипта, вне ячеек. После истечения токена войдите снова.
5. Выберите **Включить отправку по флажку**. Заполните строку и установите флажок **Отправить**. Если Google не передаёт личность редактора, используйте пункты меню отправки выбранной строки. Установленный триггер не отправляет чужие правки от имени своего владельца.

## Пример

На листе **Бюджеты** заполните строку: категория `еда`, лимит `5000`. Сохраните через флажок или пункт **Сохранить выбранный бюджет**.

На листе **Транзакции** заполните дату `2026-11-05`, сумму `450`, категорию `еда`, описание `Обед`. Отправьте строку: API вернёт ID, в статусе появится `Сохранено`. Числа вводите как числовые значения Google Таблицы; даты — как дату или текст `YYYY-MM-DD`. Повторная отправка строки с ID пропускается. После сетевой ошибки проверьте список транзакций через API перед повторной отправкой: ответ мог потеряться после записи.

На листе **Отчёт** задайте в `B2` дату `2026-11-01`, в `B3` — `2026-11-30`. Выберите **Получить отчёт**: для нового аккаунта с одной такой транзакцией итог будет `450`, использование бюджета — `9%`. Попытка добавить ещё `5000` в категорию `еда` даст ошибку превышения бюджета и не создаст запись. Отчёт отражает расходы за выбранный период; сам лимит бюджета проверяется по всем расходам категории.

Для заготовки с примерами можно запустить `createDemoSpreadsheet`: ссылка на созданную таблицу появится в журнале выполнения. В новой таблице выполните шаги 1–5, чтобы привязать скрипт и подключить свой API. Секреты и пароль не помещайте в общедоступную таблицу.

Проверка скрипта без Google-аккаунта: `node --test google-sheets/tests/code.test.cjs` из корня репозитория.
